\# Student Portal



Student Portal is a simple Java application for managing basic student information and portal operations.



\## Prerequisites



\- Java Development Kit (JDK) 17 or later

\- Git

\- A command-line terminal



\## Java Setup



1\. Install JDK 17 or later.

2\. Verify the Java installation using `java -version`.

3\. Verify the Java compiler using `javac -version`.
